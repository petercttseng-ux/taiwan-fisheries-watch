行政院核定首部整體海洋保護區管理政策方針，設定三大目標、兩大策略與十大行動，並以長期監測、治理評估、權益關係人參與、海域空間規劃、MPA與OECM推動30×30目標。水試所可提供漁業資源、棲地、生物多樣性、社經影響及氣候調適資料，協助建立可追蹤的科學基線，也支持將漁民、原住民族與地方社區納入參與治理。保護區劃設、權益協調、管理及執法由海保署與各目的事業主管機關依法辦理。
